# src/lib

## Overview

Core shared domain logic, infrastructure clients, security/rate-limiting primitives, exam formula/merge engines, clinical document fillers, scheduling/capacity rules, financial/expense analytics, and storage abstractions for FisioTrainer.

## Interface

### Child Packages
- [pdf](./pdf/README.md) — `@react-pdf/renderer` A4 PDF document components (`ComparacaoRapidaPdfDocument`, `ComprovantePdfDocument`, `ContratoPdfDocument`, `EvolucaoPdfDocument`, `RelatorioPdfDocument`) and `GreatVibes` signature font registration (`FONTE_ASSINATURA`).
- [validations](./validations/README.md) — 22 pure Zod validation modules defining domain schemas, option tuples, PT-BR labels, and parsers for scheduling, billing, expenses, clinical evolutions, exams, plans, pre-registration, rooms, services, workouts, and users.

## Invariants

### Auth, Security, Audit & Storage
- `[auth.ts:HASH_FICTICIO]` & `[auth.ts:auth]` — Credentials sign-in always checks IP lock first, atomically increments email attempt count before password verification, compares missing users against a dummy bcrypt hash to prevent user enumeration, increments IP failures only on invalid credentials, resets email attempts on success, and throws `LoginBloqueadoError` (`code = "bloqueado:<tempo>"`) when locked.
- `[sessao.ts:usuarioDaSessao]` & `[sessao.ts:exigirSessaoOuPortal]` — Clinic sessions re-verify `session.user.id` existence in `prisma.user` per request so deleted users with live JWTs are rejected (`NaoAutenticadoError`); portal bypass is allowed only inside server-side `comAcessoPortal` `AsyncLocalStorage` scope matching `pacienteId`.
- `[acesso-compartilhado.ts:gerarTokenPublico]` & `[acesso-compartilhado.ts:buscarAcesso]` — Public tokens are 32-byte base64url strings (`<= 64` chars); lookups reject blocked IPs, inactive records, soft-deleted patients (`excluidoEm != null`), and expired tokens, incrementing IP failure counters on every invalid token (`resolverPacientePorToken` invokes `notFound()`).
- `[limite-tentativas.ts:POLITICAS]`, `[limite-tentativas.ts:duracaoBloqueio]`, & `[limite-tentativas-db.ts:contarTentativa]` — Rate limiting doubles lockout duration per consecutive block (exponent `0..20`, capped at `bloqueioMaxMs`), forgets prior lockouts after `ESQUECER_BLOQUEIOS_APOS_MS` (24h), bypasses completely when `process.env.LIMITE_TENTATIVAS === "off"`, fails open on DB errors, and uses optimistic `where { chave, janelaInicio }` window resets with atomic `{ increment: 1 }`.
- `[prisma.ts:criarPrisma]` & `[audit.ts:sanitizarValorAuditoria]` — Audit logging runs for `AUDIT_WRITE_OPS` unless `AUDIT_LOG === "off"`, skips `AuditLog`/`ExameEdicaoPresenca`/`LimiteTentativa`, redacts `password`/`senha`/`hash` (`"[oculto]"`), caps recursion depth at 6 / strings at 1000 chars / arrays at 100 items, and swallows audit errors so primary DB operations never fail.
- `[storage-keys.ts:validarArquivo]`, `[storage-keys.ts:tipoPreview]`, & `[storage-keys.ts:chaveDoPaciente]` — Rejects blocked executable/script/active extensions (`EXTENSOES_BLOQUEADAS`), empty/invalid sizes, and files `> 15 MB` (`TAMANHO_MAXIMO_ARQUIVO`); restricts inline preview to safe raster images, PDF, audio, and video (excluding SVG/HTML); enforces bucket prefix ownership (`pacientes/{id}/`, `tmp/pacientes/{id}/`, `tmp/pre-cadastro/{uuid}/`) and rejects `".."` traversal.
- `[paciente-anexos.ts:criarTicketUpload]` & `[paciente-anexos.ts:registrarAnexo]` — Enforces `MAX_ANEXOS_PACIENTE` (`50`), verifies `chaveTmpDoPaciente` ownership and actual R2 object size via `headObject` before copying to permanent storage, and relies on callers for auth/authorization.
- `[r2.ts:r2]`, `[r2.ts:deleteObjects]`, & `[r2.ts:deletePrefix]` — Requires `R2_ACCOUNT_ID`, `ACCESS_KEY_ID`, and `SECRET_ACCESS_ID` (bucket defaults to `"fisiotrainer"`); batches deletes in chunks of `<= 1000` keys and paginates prefix listings until `IsTruncated === false`.
