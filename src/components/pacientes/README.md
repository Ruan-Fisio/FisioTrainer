# Pacientes Components

## Overview
Provides the patient management UI domain, covering active and soft-deleted patient tables and list items, patient create/edit forms (including curadoria pre-registration conversion), URL-synced detail tabs, monthly plan/service appointment management (supporting both clinic and read-only patient portal modes), assisted and standalone service scheduling wizards, recurring schedule editing with conflict preview, clinical history and direct-to-storage attachments, patient portal access sharing, document management, and exam image gallery with full interactive SVG annotation and side-by-side overlay comparison.

## Interface
- `[agendamento-assistido-dialog.tsx:AgendamentoAssistidoDialog]`: Client component (`"use client"`) accepting `{ pacienteId: string; label?: string; size?: "default" | "sm" }`; 3-step wizard for scheduling plan appointments.
- `[agendamento-servico-dialog.tsx:AgendamentoServicoDialog]`: Client component (`"use client"`) accepting `{ pacienteId: string; servicos: Awaited<ReturnType<typeof listAllServicos>>[number][] }`; 4-step wizard for scheduling standalone services with payment installments.
- `[anexos-paciente.tsx:AnexoItem]`: Type `{ id: string; nomeOriginal: string; mime: string; tamanho: number; createdAt: Date; origem: "CLINICA" | "PACIENTE"; url: string }`.
- `[anexos-paciente.tsx:AnexosPaciente]`: Client component (`"use client"`) accepting `{ anexos: AnexoItem[]; solicitarUpload: (input: { nome: string; mime: string; tamanho: number }) => Promise<{ error: string } | { chave: string; url: string }>; confirmar: (input: { chave: string; nomeOriginal: string }) => Promise<{ error: string } | { success: true }>; remover: (anexoId: string) => Promise<{ error: string } | { success: true }>; permitirExcluir: boolean; mostrarOrigem?: boolean; vazio?: string }`.
- `[anotacoes-camada.tsx:FormaSvg]`: Component accepting `{ forma: Forma; anotacoes: Pick<Anotacoes, "largura" | "altura" | "calibracao">; zoom?: number }` rendering SVG annotation shapes.
- `[anotacoes-camada.tsx:FormaHit]`: Component accepting `{ forma: Forma; anotacoes: Pick<Anotacoes, "largura" | "altura">; espessura: number; zoom?: number; onPointerDown: (e: React.PointerEvent) => void }` rendering transparent move hit targets.
- `[anotacoes-camada.tsx:CamadaAnotacoes]`: Component accepting `{ anotacoes: Anotacoes }` rendering a read-only `pointer-events-none` SVG overlay.
- `[anotar-imagem-dialog.tsx:AnotarImagemDialog]`: Client component (`"use client"`) accepting `{ imagem: ImagemSerie; open: boolean; onOpenChange: (open: boolean) => void; onSalvo: (anotacoes: Anotacoes | null) => void }`.
- `[comparacao-imagens-dialog.tsx:ComparacaoImagensDialog]`: Client component (`"use client"`) accepting `{ base: ImagemSerie; sobreposta: ImagemSerie; open: boolean; onOpenChange: (open: boolean) => void }`.
- `[compartilhar-acesso-dialog.tsx:CompartilharAcessoDialog]`: Client component (`"use client"`) accepting `{ pacienteId: string }`.
- `[grade-recorrente-dialog.tsx:GradeRecorrenteDialog]`: Client component (`"use client"`) accepting `{ atribuicaoId: string; planoNome: string; modalidades: ModalidadePlano[]; atendimentos: number | null; linhasIniciais: GradeRecorrenteLinha[]; opcoes: GradeOpcoes }`.
- `[historico-clinico-dialog.tsx:HistoricoClinicoDialog]`: Client component (`"use client"`) accepting `{ paciente: HistoricoPaciente & { id: string }; anexos: AnexoItem[] }`.
- `[paciente-agendamentos-tab.tsx:PacienteAgendamentosTab]`: Client component (`"use client"`) accepting `{ pacienteId: string; resumoInicial: Resumo; anoInicial: number; mesInicial: number; somenteLeitura?: boolean; gradeContexto?: GradeContexto; agendamentosServicoInicial?: AgendamentosServico; servicos?: Servico[] }`.
- `[paciente-documentos-tab.tsx:PacienteDocumentosTab]`: Client component (`"use client"`) accepting `{ pacienteId: string; documentos: DocumentoListado[] }`.
- `[paciente-form.tsx:PacienteForm]`: Client component (`"use client"`) accepting `{ action: (prevState: PacienteActionState, formData: FormData) => Promise<PacienteActionState>; defaultValues?: { nome: string; sexo: "MASCULINO" | "FEMININO" | null; idade: number | null; dataNascimento: string | null; cpf: string | null; email: string | null; contato: string | null; endereco: string | null; historicoClinico: string | null; objetivo: string | null; doencasPreexistentes: string | null; cirurgiasAnteriores: string | null; medicamentos: string | null; numeroIndicacao: string | null; pessoaIndicacao: string | null }; mode: "create" | "edit"; preCadastroId?: string }`.
- `[paciente-imagens-tab.tsx:PacienteImagensTab]`: Client component (`"use client"`) accepting `{ series: SerieImagens[] }`.
- `[paciente-list-item.tsx:PacienteTableRow]` and `[paciente-list-item.tsx:PacienteCard]`: Client components (`"use client"`) accepting `{ id: string; nome: string; idade: number | null; contato: string | null; execucoesCount: number }`.
- `[paciente-multi-select.tsx:PacienteOption]`: Type `{ id: string; nome: string }`.
- `[paciente-multi-select.tsx:PacienteMultiSelect]`: Client component (`"use client"`) accepting `{ options: PacienteOption[]; value: string[]; onChange: (ids: string[]) => void; placeholder?: string }`.
- `[paciente-row-actions.tsx:PacienteRowActions]`: Client component (`"use client"`) accepting `{ id: string; nome: string }`.
- `[paciente-tabs.tsx:PacienteTabs]`: Client component (`"use client"`) accepting `{ tabs: { value: string; label: string; icon?: ReactNode; action?: ReactNode; content: ReactNode }[]; defaultValue: string }`.
- `[pacientes-excluidos.tsx:PacientesExcluidos]` and `[pacientes-table.tsx:PacientesTable]`: Async server components accepting `{ page: number; search: string }`.
- `[restaurar-paciente-button.tsx:RestaurarPacienteButton]`: Client component (`"use client"`) accepting `{ id: string }`.

## Invariants
- `[agendamento-assistido-dialog.tsx:AgendamentoAssistidoDialog]`: 3-step wizard (`1 | 2 | 3`) resetting all selections on close (`resetar`); loads options lazily once when opened (auto-selecting when `opcoes.length === 1`), filters `profissionaisVisiveis` by plan modality, blocks step 2 dates when `dispMes?.limiteAtingido`, and requires `opcao`, `diaSelecionado`, `horaSelecionada`, and `!isPending` to confirm.
- `[agendamento-servico-dialog.tsx:AgendamentoServicoDialog]`: 4-step wizard resetting on close; builds 30-minute slots from `INICIO_EXPEDIENTE` (07:00) to `FIM_EXPEDIENTE` (21:00) marking overlaps or past same-day slots as `vagas: 0`, computes `maxParcelas` via `maxParcelasPlano("TRIMESTRAL", formaPagamento)` (clamping `vencimentos` and requiring `>= 1` due date and truthy `valorNumero`), and derives `horaFim` by adding `DURACAO_HORARIO_LIVRE_MIN`.
- `[anexos-paciente.tsx:handleFiles]`: Validates every file with `validarArquivo(file.name, file.size)` before upload, groups by day via `agruparPorDia`, shows origin badge only when `mostrarOrigem && anexo.origem === "PACIENTE"`, and renders two-step deletion only when `permitirExcluir` is `true`.
- `[anotacoes-camada.tsx:medidasDe]`: Maps normalized coordinates `[0..1]` into image pixel space `(p.x * l, p.y * h)` and scales stroke/font sizes inversely with `zoom`.
- `[anotar-imagem-dialog.tsx:AnotarImagemDialog]`: Supports 9 tools (`mover`, `linha`, `seta`, `medida`, `angulo`, `circulo`, `livre`, `texto`, `calibrar`) and 3 alignment modes (`livre`, `ima`, `travar`); caps undo history (`passado`) at 50 snapshots and freehand strokes (`livre`) at 600 points, discards freehand shapes with `<= 3` points or 2-point shapes shorter than `0.01`, truncates text to 80 chars and strips empty text before save (emitting `null` to `onSalvo` when no shapes remain), blocks outside-click dismissal, and requires `confirmarSaida` confirmation when closing with unsaved changes (`sujo`).
- `[comparacao-imagens-dialog.tsx:GradeNumerada]`: Renders a fixed 13x17 postural grid (`A`–`L` by `1`–`16`) with `vectorEffect="non-scaling-stroke"`; `[comparacao-imagens-dialog.tsx:ComparacaoImagensDialog]` bounds opacity blend `mistura` to `0..100` and synchronizes base/overlay annotation opacity (`1 - mistura/100` vs `mistura/100`).
- `[compartilhar-acesso-dialog.tsx:CompartilharAcessoDialog]`: Lazily fetches/creates token only when `open && !token`, builds `${baseUrl}/compartilhado/paciente/${token}`, and disables revoke while `!token || revogando`.
- `[grade-recorrente-dialog.tsx:GradeRecorrenteDialog]`: Returns `null` when `modalidades.length === 0`; any edit clears `conflitos` (`atualizarLinhas`) so saving always runs `verificarConflitosGrade` first and blocks on conflicts unless explicitly confirmed; `[grade-recorrente-dialog.tsx:ConflitosGrade]` displays at most 8 conflicts plus a remainder count.
- `[historico-clinico-dialog.tsx:HISTORICO_FIELDS]`: Renders 5 clinical fields (`historicoClinico`, `objetivo`, `doencasPreexistentes`, `cirurgiasAnteriores`, `medicamentos`), falling back to `"—"` when falsy.
- `[paciente-agendamentos-tab.tsx:PacienteAgendamentosTab]`: Normalizes months with `startOfMonth`, reuses `resumoInicial` for the initial month without refetching, and clears `outroMes` cache when `resumoInicial` changes; in `somenteLeitura` portal mode switches to a 2-level plan list/detail view, hides clinic actions and standalone services, and exposes `[paciente-agendamentos-tab.tsx:DesmarcarSlotButton]` guarded by `pacientePodeDesmarcar` (2-hour deadline) and `motivo.trim().length >= 3`.
- `[paciente-form.tsx:PacienteForm]`: Freezes `preCadastroIdProp` in initial `useState` so post-submit re-renders preserve redirect destination (`/curadoria` vs `/pacientes`), emits hidden `preCadastroId` when set, and enforces HTML constraints (`nome` required, `idade` `min={0}`, `dataNascimento` date, `email` email, `sexo` enum).
- `[paciente-imagens-tab.tsx:alternar]`: Caps per-series comparison selection to at most 2 images via `[...atual, imagemId].slice(-2)`, overlays session-local saved annotations (`comLocais`) over server data, and disables Compare until 2 images are selected.
- `[paciente-tabs.tsx:PacienteTabs]`: Validates `searchParams.get("tab")` against `tabs`, falls back to `defaultValue`, and deletes the `"tab"` query param when switching back to `defaultValue`.
- `[paciente-row-actions.tsx:PacienteRowActions]`: Stops click propagation (`event.stopPropagation()`) so row/card clicks do not fire when interacting with actions; disables delete confirm while `isPending`; `[pacientes-excluidos.tsx:PacientesExcluidos]` asserts non-null `p.excluidoEm!`.

## Side Effects
- `[agendamento-assistido-dialog.tsx:AgendamentoAssistidoDialog]`: Invokes context-provided actions from `useAcoesAgendamento` (`getDadosAgendamentoAssistido`, `getDisponibilidadeMesAssistido`, `getDisponibilidadeHorarios`, `criarAgendamentoAssistido`), triggers `toast.success(...)`, and calls `router.refresh()`.
- `[agendamento-servico-dialog.tsx:AgendamentoServicoDialog]`: Invokes server actions `getProfissionaisServico`, `getDisponibilidadeMes`, `getAgendamentosDoDia`, and `criarAgendamentoServico`, triggers `toast.success(...)`, and calls `router.refresh()`.
- `[anexos-paciente.tsx:enviar]`: Calls `crypto.randomUUID()`, invokes injected `solicitarUpload`, performs direct HTTP `fetch(ticket.url, { method: "PUT", ... })`, invokes injected `confirmar` or `remover`, calls `toast.error(...)` on delete failure, and calls `router.refresh()`.
- `[anotar-imagem-dialog.tsx:salvar]`: Calls server action `salvarAnotacoesImagem(imagem.id, limpo)` inside `useTransition`, triggers toast feedback, invokes `onSalvo` and `onOpenChange(false)`; attaches `ResizeObserver`, non-passive stage `wheel`, global `window` `keydown` listeners, pointer capture, and mutates module-level `contador` (`novoId`).
- `[compartilhar-acesso-dialog.tsx:CompartilharAcessoDialog]`: Calls server actions `getOuCriarAcessoPaciente` and `revogarAcessoPaciente`, writes to `navigator.clipboard`, uses `window.location.origin` and a 2000 ms `setTimeout`, triggers toast feedback, and calls `router.refresh()`.
- `[grade-recorrente-dialog.tsx:GradeRecorrenteDialog]`: Calls server actions `previewGradeRecorrente` (400 ms debounced), `verificarConflitosGrade`, and `salvarGradeRecorrente`, triggers `toast.success(...)`, and calls `router.refresh()`.
- `[paciente-agendamentos-tab.tsx:PacienteAgendamentosTab]`: Calls `getConsumoPlanoPaciente`, `listAgendamentosServicoPaciente`, `atualizarStatusAgendamento`, and `desmarcarAgendamentoPeloPaciente`, triggers toast feedback, and calls `router.refresh()`.
- `[paciente-documentos-tab.tsx:ExcluirDocumento]`: Calls `excluirDocumento(doc.id)` with toast feedback; `[paciente-documentos-tab.tsx:Acoes]` opens `/api/documentos/${doc.id}/pdf` in a new tab.
- `[paciente-form.tsx:PacienteForm]`: Submits `FormData` via `useActionState`, triggers `toast.success(...)`, and calls `router.push(preCadastroId ? "/curadoria" : "/pacientes")`.
- `[paciente-list-item.tsx:PacienteTableRow]` and `[paciente-list-item.tsx:PacienteCard]`: Navigate to `/pacientes/${id}` via `router.push`.
- `[paciente-row-actions.tsx:handleDelete]` and `[restaurar-paciente-button.tsx:RestaurarPacienteButton]`: Call `deletePaciente(id)` and `restaurarPaciente(id)` with toast feedback.
- `[paciente-tabs.tsx:onValueChange]`: Updates URL via `router.replace(..., { scroll: false })`.
- `[pacientes-excluidos.tsx:PacientesExcluidos]` and `[pacientes-table.tsx:PacientesTable]`: Call `await listPacientes(...)` during server render.
