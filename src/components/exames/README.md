# exames

## Overview
Exam template authoring, formula/reference-table editing, collaborative real-time autosave, and catalog listing UI package. Combines the multi-section exam builder and live preview (`ExameForm`), autocomplete formula/condition modal (`FormulaDialog`), spreadsheet-style reference table editor (`TabelasReferenciaEditor`), real-time 3-way-merge autosave hook and floating status bar (`useEdicaoTempoReal`, `StatusEdicaoFlutuante`), option highlight color selector (`CorOpcaoSelect`), and paginated catalog listing/filtering/actions (`ExamesTable`, `ExameFilters`, `ExameTableRow`, `ExameCard`, `ExameRowActions`).

## Interface
- `[exame-form.tsx:ExameForm]` — Client Component (`{ action?, defaultValues?, mode: "create" | "edit", edicao?: { exameId: string; carregadoEm: string; editores: string[] } }`) rendering the exam builder form, live preview sidebar, mobile stepper, desktop drag-reorderable sections, and real-time sync integration.
- `[formula-dialog.tsx:AlvosAgregacaoContext]` — React Context (default `[]`) supplying aggregation targets (`SOMA`/`MEDIA`/`MIN`/`MAX`/`CONTAGEM`) to `FormulaDialog` and `FormulaEditor`.
- `[formula-dialog.tsx:FormulaDialog]` — Client Component (`{ titulo, modo: "formula" | "condicao", valorInicial, colunasDisponiveis, variaveis, onVariaveisChange, onRenomearVariavel, onAplicar, onFechar }`) providing formula/condition editing with autocomplete, live fictional-value preview, and inline variable management.
- `[tabelas-referencia-editor.tsx:VariaveisTabelasContext]` — React Context (default `[]`) exposing `{Tabela.Saída}` `VariavelExame[]` entries generated from reference tables.
- `[tabelas-referencia-editor.tsx:useVariaveisTabelas]` — Client hook returning `VariavelExame[]` from `VariaveisTabelasContext`.
- `[tabelas-referencia-editor.tsx:TabelasReferenciaEditor]` — Client Component (`{ tabelas, onChange, colunasNumericas, onRenomearReferencia }`) managing reference tables and the spreadsheet draft modal (`TabelaDialog`).
- `[cor-opcao-select.tsx:CorOpcaoSelect]` — Client Component (`{ value: string; rotulo: string; onChange: (cor: string) => void }`) rendering a highlight-color radio group.
- `[exame-filters.tsx:ExameFilters]` — Component (`{ search: string }`) wrapping `SearchInput`.
- `[exame-list-item.tsx:ExameTableRow]` & `[exame-list-item.tsx:ExameCard]` — Client Components (`{ id, nome, descricao, tipo, secoesCount, execucoesCount }`) rendering clickable desktop table row and mobile card views.
- `[exame-row-actions.tsx:ExameRowActions]` — Client Component (`{ id: string; nome: string; execucoesCount: number }`) rendering view/edit links and usage-gated delete controls.
- `[exames-table.tsx:ExamesTable]` — Async Server Component (`{ page: number; search: string }`) fetching and rendering paginated exam templates.
- `[status-edicao-flutuante.tsx:StatusEdicaoFlutuante]` — Client Component (`{ estado: EstadoEdicao; onSincronizarAgora: () => void; onMostrarErro: (path?: (string | number)[]) => void }`) rendering the fixed live-sync status pill (`role="status"`, `aria-live="polite"`) and expandable details panel.
- `[use-edicao-tempo-real.ts:INTERVALO_SINCRONIZACAO_MS]` — Periodic sync interval constant (`10_000` ms).
- `[use-edicao-tempo-real.ts:FaseSincronizacao]`, `[use-edicao-tempo-real.ts:ErroSincronizacao]`, `[use-edicao-tempo-real.ts:AlteracaoRecebida]`, `[use-edicao-tempo-real.ts:EstadoEdicao]` — Exported real-time sync state/error/change types.
- `[use-edicao-tempo-real.ts:useEdicaoTempoReal]` — Client hook (`{ ativo, inicial, editoresIniciais, draftAtual, aplicarMerge }`) returning `{ estado, sincronizarAgora, temAlteracoes }`.

## Invariants
- `[exame-form.tsx:ExameForm]` — `secoes` initializes to `defaultValues.secoes` if non-empty else `[novaSecao()]`; `tipoExame` is restricted to `"FISIOTERAPIA" | "EDUCACAO_FISICA"` (default `"FISIOTERAPIA"`); real-time editing activates only when `mode === "edit" && Boolean(edicao)`; create mode submits via `useActionState`, while edit mode sets `action={undefined}` and intercepts `onSubmit` to call `concluir()`.
- `[exame-form.tsx:SecaoCard]` — Prevents deleting the last section (`totalSecoes === 1`), field (`secao.campos.length === 1`), column (`campo.colunas.length === 1`), or below 2 options (`coluna.opcoes.length <= 2`); switching to `MULTIPLA_ESCOLHA` pads `< 2` options to `["", ""]`, and switching away clears `opcoesCondicionais` and sets `usaPontuacao = false`; flags `coluna.usaPontuacao && campo.repetivel` as invalid; enforces HTML `required` on `secao.nome`, `coluna.titulo`, and option inputs.
- `[exame-form.tsx:semIds]` & `[exame-form.tsx:semIdsCampo]` — Duplicated sections, fields, and columns always receive fresh `novoIdLocal()` IDs; `[exame-form.tsx:aplicarMerge]` remaps IDs via `remapearSecoes` and preserves React/DnD stability via `chavesEstaveis` (`[exame-form.tsx:chaveItem]`).
- `[exame-form.tsx:updateSecao]`, `[exame-form.tsx:updateColuna]`, `[exame-form.tsx:renomearVariavelNasColunas]` — Renaming sections, columns, variables, or reference-table outputs propagates references across formulas, variables, and (for non-repeatable columns) reference tables whenever normalized titles change; `[exame-form.tsx:addOpcao]` / `[exame-form.tsx:removeOpcao]` / `[exame-form.tsx:updateOpcao]` keep `opcoes`, `coresOpcoes`, `pontuacoes`, and `opcoesCondicionais` index-aligned.
- `[exame-form.tsx:FormulaEditor]` — Validates `{ref}` tokens against `AlvosAgregacaoContext` (for `parseAgregacao`), `colunasDisponiveis`, `VARIAVEIS_PACIENTE`, `ehSomaPontuacoes`, `variaveis`, and `useVariaveisTabelas()`; inputs nest inside `<Label>` without `id`/`htmlFor` because mobile wizard and desktop views coexist in the DOM.
- `[exame-form.tsx:destacarErroNoForm]` — Matches DOM IDs `tabela-ref-${tabelaIndex}`, `exame-coluna-${secaoIndex}-${campoIndex}-${colunaIndex}`, and `exame-opcao-${secaoIndex}-${campoIndex}-${colunaIndex}-${opcaoIndex}`, ignoring `variaveis` paths.
- `[formula-dialog.tsx:FormulaDialog]` — Switches autocomplete to aggregation targets when `dentroDeAgregacao` is true, intercepts `Escape` to close only the listbox when open (`[formula-dialog.tsx:aoTeclar]`), prevents variable-name collisions under `normalizarTitulo` (`[formula-dialog.tsx:adicionarVariavel]`), and defaults preview inputs to `"30"` (`idade`), `"1"` (`sexo`), or `"10"` (`[formula-dialog.tsx:valorPadrao]`).
- `[tabelas-referencia-editor.tsx:TabelaDialog]` — Edits an isolated `structuredClone` draft, guards unsaved dismissal via `JSON.stringify` diff, enforces at least 1 key, 1 output, and 1 row (`[tabelas-referencia-editor.tsx:ListaNomes]`), blocks save on `validarTabelas([tabela])` failure, intercepts clipboard paste only on `/[\t\n]/` (`[tabelas-referencia-editor.tsx:colar]`), and restricts `tipo === "sexo"` cells to `""`, `"1"`, or `"0"`.
- `[cor-opcao-select.tsx:CorOpcaoSelect]` — Normalizes invalid values failing `ehCorOpcao(value)` to `""`; `[exame-row-actions.tsx:ExameRowActions]` disables deletion when `execucoesCount > 0` (`emUso`) and stops click propagation; `[exames-table.tsx:ExamesTable]` renders an empty-state card when `exames.length === 0`.
- `[use-edicao-tempo-real.ts:rodarCiclo]` — Serializes sync cycles via `executando` ref, retries optimistic-lock conflicts (`r.conflito`) or mid-fetch local edits at most 3 times (`[use-edicao-tempo-real.ts:executar]`), pulls remote edits even on validation error, and skips merge when version/id are unchanged (`[use-edicao-tempo-real.ts:absorver]`); all listeners and timers are no-ops when `ativo` is false.
- `[status-edicao-flutuante.tsx:DESTAQUE_RECEBIDO_MS]` — Highlights recent remote updates for `6000` ms, clamps timers to `>= 0`, disables manual sync while `fase !== "ocioso"`, shows `"Salvar agora"` only when `pendente || erro?.tipo === "falha"`, and shows `"Mostrar onde"` only when `erro?.tipo === "invalido"`.

## Side Effects
- `[exame-form.tsx:ExameForm]` — In create mode, submits serialized JSON (`secoes`, `variaveis`, `tabelas`, `sombra`) via `useActionState`, displays Sonner toasts, and navigates to `/exames`; in edit mode, runs `useEdicaoTempoReal` and navigates to `/exames` on `concluir()` or cancel; highlights validation errors via `setTimeout`, double `requestAnimationFrame`, `document.getElementById`, `scrollIntoView`, and transient CSS classes (`[exame-form.tsx:destacarErroNoForm]`).
- `[formula-dialog.tsx:posicionar]` — Schedules `requestAnimationFrame` to focus the textarea and call `setSelectionRange`; variable mutations immediately invoke `onVariaveisChange` / `onRenomearVariavel`.
- `[tabelas-referencia-editor.tsx:colar]` — Reads `e.clipboardData.getData("text/plain")` and calls `e.preventDefault()` on multi-cell paste; save/delete invoke `onChange` and `onRenomearReferencia`.
- `[use-edicao-tempo-real.ts:useEdicaoTempoReal]` — Invokes server actions `sincronizarExame`, `autosalvarExame`, and `sairDaEdicaoExame` (on unmount/deactivation); manages `10_000` ms `setTimeout` polling and 50 ms post-render waits; calls `window.history.replaceState` when the exam ID changes; registers `document` `"visibilitychange"` and `window` `"beforeunload"` listeners.
- `[status-edicao-flutuante.tsx:StatusEdicaoFlutuante]` — Runs a `1000` ms `setInterval` ticking local clock state (cleared on unmount).
- `[exame-list-item.tsx:ExameTableRow]` & `[exame-list-item.tsx:ExameCard]` — Navigate via ``router.push(`/exames/${id}`)`` on click.
- `[exame-row-actions.tsx:ExameRowActions]` — Calls server action `deleteExame(id)` inside `startTransition` and emits `toast.success` / `toast.error`.
- `[exames-table.tsx:ExamesTable]` — Awaits server query `listExames({ q: search }, page)` on render.
