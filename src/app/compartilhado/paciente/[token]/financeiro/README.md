# financeiro

## Overview
Route segment grouping shared patient portal financial detail pages under `/compartilhado/paciente/[token]/financeiro`.

## Subdirectories & Boundaries
- `[planoId]`: [`./[planoId]/README.md`](./%5BplanoId%5D/README.md) - Token-scoped financial detail page (`FinanceiroPlanoPublicoPage`) rendering read-only charges for an assigned plan or standalone (`"avulsas"`) charges.
