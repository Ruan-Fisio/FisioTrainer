# [atribuicaoId]

## Overview
Dynamic route segment directory (`/pacientes/[id]/planos/[atribuicaoId]`) grouping routes that operate on a single patient plan assignment. Contains no direct page or layout files.

## Subdirectories & Boundaries
- editar: [./editar/README.md](./editar/README.md) - Server page (`EditarAtribuicaoPlanoPage`) for editing an existing patient plan assignment via `PlanoAtribuicaoForm` and `updatePlanoAtribuicao`.
