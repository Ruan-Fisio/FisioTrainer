# [treinoId]

## Overview
Dynamic route segment directory (`/pacientes/[id]/treinos/[treinoId]`) grouping routes that operate on a single patient workout record. Contains no direct page or layout files.

## Subdirectories & Boundaries
- editar: [./editar/README.md](./editar/README.md) - Server page (`EditarTreinoPacientePage`) for editing a patient workout via `TreinoForm` and `updateTreinoPaciente`.
