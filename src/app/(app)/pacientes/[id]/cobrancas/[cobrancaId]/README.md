# [cobrancaId]

## Overview
Dynamic route segment directory (`/pacientes/[id]/cobrancas/[cobrancaId]`) grouping routes that operate on a single patient charge record. Contains no direct page or layout files.

## Subdirectories & Boundaries
- editar: [./editar/README.md](./editar/README.md) - Server page (`EditarCobrancaPage`) for editing a patient's charge record via `CobrancaForm` and `updateCobranca`.
