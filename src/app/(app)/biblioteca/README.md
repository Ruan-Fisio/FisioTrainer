# Biblioteca Routes (`biblioteca`)

## Overview
Intermediate Next.js App Router grouping for the exercise library, organizing exercise category management and exercise catalog routes.

## Subdirectories & Boundaries
- `categorias`: [./categorias/README.md](./categorias/README.md) - Exercise category listing, search, pagination, creation, and editing routes.
- `exercicios`: [./exercicios/README.md](./exercicios/README.md) - Exercise catalog listing, search, category filtering, detail view, creation, and editing routes.
